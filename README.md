# 📚 Documents

مجموعه‌ای شخصی از **تحقیقات، یادداشت‌ها و مستندات آموزشی** من در موضوعات مختلف فناوری و نرم‌افزار.

> هر موضوع در پوشه‌ی مخصوص خودش قرار دارد تا پیدا کردن و به‌روزرسانی مطالب ساده باشد.

## 🎯 هدف این ریپازیتوری

- نگهداری منظم نتایج تحقیقات و یادگیری‌های من
- داشتن یک مرجع سریع برای مراجعه در آینده
- اشتراک‌گذاری دانسته‌ها با دیگران

```text

└── <topic-name>/

    ├── notes/           # یادداشت‌ها
    ├── examples/        # نمونه کدها
    └── assets/          # تصاویر و فایل‌های پیوست
```

## ➕ افزودن موضوع جدید

1. یک پوشه با نام کوچک و بدون فاصله بسازید (مثلاً `docker` یا `dotnet`):

   ```bash
   mkdir docker
   ```

2. داخل آن یک فایل `README.md` برای معرفی موضوع و فهرست مطالب بگذارید.
3. مطالب و تحقیقات را در همان پوشه اضافه کنید.
4. ردیف جدید را به جدول «فهرست موضوعات» همین فایل اضافه کنید.
5. تغییرات را کامیت و پوش کنید:

   ```bash
   git add .
   git commit -m "docs: add docker research"
   git push
   ```

---

## 📝 قواعد نام‌گذاری

- نام پوشه‌ها: حروف کوچک انگلیسی و با خط تیره (`design-patterns`)
- نام فایل‌ها: توصیفی و بدون فاصله (`install-and-setup.md`)
- فرمت مستندات: Markdown (`.md`)
- پیام کامیت‌ها: `docs: ...` برای مستندات، `fix: ...` برای اصلاحات
